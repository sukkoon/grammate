<Voices>
<Voice level="middle">

먼저 짧게 정리할게요. 현실과 반대로 상상할 때는 시제를 한 칸 뒤로 물려요. **가정법 과거**(If + 과거형, would + 동사원형)는 지금 사실의 반대, **가정법 과거완료**(If + had p.p., would have p.p.)는 과거 사실의 반대예요. I wish, as if 뒤에서도 같은 규칙이 통했죠.

이번 단원에서는 이 규칙을 응용하는 기술 네 가지를 배워요. 두 시간을 **섞는** 혼합가정법, if를 **빼고** 순서를 뒤집는 도치, if 대신 쓰는 **without과 but for**, 그리고 문장 속에 **숨은 조건**이에요. 수능 독해에서 &lsquo;실제로는 어땠는지&rsquo;를 읽어 내는 힘이 여기서 나와요.

</Voice>
<Voice level="high">

가정법의 모든 변형은 두 가지 원리에서 나와요. 첫째, 각 절의 정동사는 자기 때에서 한 칸씩 물러서요. 둘째, 조건은 if절이 아니어도 도치·전치사구·to부정사·주어 같은 다른 모양에 숨을 수 있어요. 그래서 if가 안 보여도 would·could가 있으면 조건을 찾고, 조건이 절에서 구로 바뀌면 정동사가 하나 줄어요. 고난도 어법은 if가 생략된 도치와 혼합가정법을 한 문장에 넣어 두 절의 시제가 서로 다른 게 맞는지 묻는 게 단골이에요.

</Voice>
</Voices>

<KeyIdea>if절과 주절의 때가 다르면 각자 자기 때에서 한 칸씩 물러서요(혼합가정법). if를 빼면 were·had·should가 주어 앞으로 나와요. if가 안 보여도 would·could가 있으면 숨은 조건을 찾아요.</KeyIdea>

## 혼합가정법: 과거의 일, 지금의 결과

<TermAnatomy id="mixed-conditional" />

<Voices>
<Voice level="middle">

과거에 한 일이 지금까지 영향을 미칠 때가 있어요. &lsquo;어젯밤에 일찍 잤더라면, **지금** 피곤하지 않을 텐데.&rsquo; if절은 과거 사실의 반대라서 had p.p., 주절은 지금 사실의 반대라서 would + 동사원형이에요. 두 절이 **각자 자기 때에서 한 칸씩** 물러선 거예요.

</Voice>
<Voice level="high">

혼합가정법은 두 절이 서로 다른 때의 반대를 말하는 구문이라, if절과 주절의 시제가 어긋나 보이는 게 정상이에요. 원리는 같아요. 각 절의 정동사가 자기 때에서 한 칸 물러설 뿐이에요. 그래서 짝이 어긋났다고 무조건 고치면 안 되고, 각 절에 붙은 시간 부사가 어느 때를 가리키는지 먼저 확인해요. 실제 사실로 되돌릴 때도 if절은 과거, 주절은 현재로 각각 따로 복원해요.

</Voice>
</Voices>

<Figure caption="if절은 과거에서, 주절은 지금에서 각자 한 칸씩 물러서요. now, still, today가 주절의 단서예요.">
  <SjMixed />
</Figure>

## if를 빼면 순서가 뒤집혀요

<TermAnatomy id="inversion" />

가정법의 if절에 **were, had, should**가 있으면 if를 빼고 이 말을 **주어 앞으로** 보낼 수 있어요. 의문문처럼 순서가 뒤집히는 거예요. 뜻은 if가 있을 때와 똑같고, 글에서 자주 쓰는 조금 격식 있는 말투예요.

<Figure caption="if가 빠진 자리를 동사가 채워요. 앞으로 나올 수 있는 건 were, had, should 셋뿐이에요.">

</Figure>

### If + 주어 + should: 혹시라도 ~한다면

should가 if절에 들어가면 &lsquo;**혹시라도** ~한다면&rsquo;이라는 뜻이 돼요. 일어날 가능성은 낮지만 아예 없지는 않은 일이라, 주절에 will이나 명령문도 올 수 있어요. 이 should도 if를 빼고 앞으로 나올 수 있어요.

<Examples>

이 단원의 문장들을 공식으로 세어 봐요. **진짜 동사 개수 = 접속사·관계사 개수 + 1**이에요.

  <SjVerbCount set="advanced" />

- **if 생략 도치**: 주어 앞으로 나온 **were, had, should가 if의 흔적**이에요. 문장 맨 앞의 &lsquo;동사 + 주어&rsquo; 순서를 보면 &lsquo;if가 빠졌구나&rsquo; 하고 읽어요.

<ExamPoint title="수능 어법·독해 포인트" level="high">

- **시간 단서로 짝 맞추기**: if절에 과거 표시(last night, as a child)가 있고 주절에 now가 있으면 혼합가정법이에요. If + had p.p., would + 동사원형
- **도치 알아보기**: 문장 맨 앞의 Were, Had, Should + 주어는 if가 빠진 조건절이에요. 쉼표 뒤에 would, could가 따라와요.
- **without, but for 바꾸기**: 주절이 would + 동사원형이면 If it were not for, would have p.p.면 If it had not been for예요.
- **숨은 조건**: if가 없는데 would, could have p.p.가 보이면 otherwise, to부정사, 주어, with·without 속의 조건을 찾아요. 빈칸 추론에서 &lsquo;실제로는 반대였다&rsquo;는 속뜻이 정답의 단서가 돼요.
- 실제 사실은 늘 **긍정과 부정을 뒤집고 시제를 한 칸 앞으로** 되돌려서 읽어요.

</ExamPoint>
